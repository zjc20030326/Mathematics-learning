# HMB 非零光场边界 RHP：硕士论文研究初稿

本工程使用指定复旦毕业论文模板，包含六章正文、中英文摘要、符号表、附录、九条参考文献以及可复现计算。目标是形成可阅读、可编译、明确区分已证结论与未解决问题的研究初稿。

- 直接阅读：[fduthesis.pdf](fduthesis.pdf)。
- 主源码：[fduthesis.tex](fduthesis.tex)。
- 数学成果、条件及待办：[RESEARCH_STATUS.md](RESEARCH_STATUS.md)。
- 文献核对记录：[REFERENCES.md](REFERENCES.md)。
- 编译与计算复现：[BUILD.md](BUILD.md)。

正文的主要结果是：完整Lax对与背景相位核验、远离阈值的Jost解析列、跳跃和四点留数的推导、一轨道无反射RHP及三场重构、限定类唯一性，以及固定传播截面的条件性共振反射结论。已完成一个非平凡参数例的精确PDE代回及一重、二重解的高精度检查。

一般含反射逆问题、分支点统一局部理论、一般复谱多孤子的完整标准RHP对应和高能余项估计仍有未完成部分。已有Darboux波形与理论均注明来源；本稿不宣称新波形或世界首次。

PowerShell构建入口为 build.ps1，后端为XeLaTeX与BibTeX。原模板入口和类文件备份在evidence目录；当前类文件仅作一处ctexbook版本检查兼容修改。作者、导师等个人信息为“待填写”，模板声明页仅用于试排。
