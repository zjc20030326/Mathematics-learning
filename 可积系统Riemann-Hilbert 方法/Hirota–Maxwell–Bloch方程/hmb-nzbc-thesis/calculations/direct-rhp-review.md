## 主要修改

- 第五章从第四章的部分分式式和留数系统出发。先选择满足换叶及相位约束的一轨道范数常数，再列出两个二阶系数矩阵和两个右端项，完成 Schur 消元，显式给出四个二维列向量。
- Schur 行列式分解为两个正因子的乘积，证明所选数据在全部实时空上可解。投影矩阵仅在求解后作为系数的代数因式分解引入，没有作为求解输入。
- 定理 5.1 验证完整四点轨道的留数、两处归一化、共轭及换叶约化、行列式、特殊点行为和唯一性。唯一性直接归结为有限维系统的可逆性。
- 定理 5.2 从同一矩阵重构三个场。两个共振原像给出相同介质矩阵，保持 Hermitian 约化、迹零和 Bloch 长度；左右光场与极化均恢复指定的共同相位。
- 对数导数的有限极点消去、分支点固定核及无穷远增长确定完整 Lax 对；零曲率比较证明原 HMB 三条方程。传播矩阵中的积分常数由显式端态确定，不调用 Darboux 定理。
- Darboux 内容移至第五章最后。对 Li–He–Porsezian 的同背景、同列解构造证明光场、极化及反转三场恒等；保留已有多次变换及二重图像，并与一般多轨道直接 RHP 的条件性表示区分。
- 第一章更新研究主线；第三章补上范数常数定义；第四章明确系数矩阵的维数、特殊点条件与逆重构的逻辑范围；第六章改为引用新的 RHP 重构定理。第二章、主文件、模板和参考文献条目不变。

## 独立验证与复现

在论文目录运行下列命令。Python 依赖为 `sympy`、`mpmath`；编译使用现有 TeX Live 和 `build.ps1`。

```powershell
$env:PYTHONDONTWRITEBYTECODE = '1'
python scripts/verify_direct_algebra.py
python scripts/verify_direct_rhp.py
python scripts/verify_symbolic.py
python scripts/verify_analysis.py
python scripts/verify_exact_example.py
python scripts/verify_rhp.py
python scripts/verify_solitons.py
./build.ps1
```

`verify_direct_algebra.py` 把指数变量及其共轭作为代数独立变量，实际计算 Schur 逆，验证显式列解、正因子分解、部分分式与紧凑矩阵的恒等关系、换叶关系、两处归一化及光场重构。完整精确结果见 `direct-algebra-results.json`。

`verify_direct_rhp.py` 的 `ResidueSolution(Q, zeta, constants, x, z, F)` 接口接受离散谱和范数常数，通过两个右端项求解留数块矩阵。输入须满足论文的数据约束；接口本身不构成一般数据可解性判断。计算矩阵和三个场均不调用投影或 Darboux 场；全部 RHP、Lax 和 PDE 检查结束后，才导入旧实现进行三场对照。

## 数学问题与结论范围

1. **第四章公式审查**：未发现部分分式、两组留数符号、Schur 补或重构公式的数学错误。原有“留数系统可解”确实不自动证明完整 HMB 逆问题，本次对指定一轨道补齐其余条件。
2. **已补齐的关键论证**：分支点处行列式为零，但换叶固定核使两个 Lax 对数导数中的逆矩阵极点可去；共振留数恰为介质矩阵；传播多项式系数及积分常数由零曲率和端态唯一确定。无需通过已有 Darboux 定理证明一轨道场满足方程。
3. **一般多轨道问题尚未解决**：保留矩阵逆及 Cramer 表示，但没有证明所有满足配对及 theta condition 的简单数据都使 Schur 矩阵全局可逆，也没有据此声称一般 N 轨道同相边界 HMB 定理。
4. **一般含反射逆问题尚未解决**：分支点、交叉轮廓及共振振荡的全局可解性仍不在本次定理内。共振反射及有限阶正则性结果保留原假设。
5. **文献对应的范围**：已读取本地 Li–He–Porsezian（2013）式 (2.2)–(2.4)、(3.16)–(3.20) 及 Zhao–Zhaqilao（2026）式 (1)–(12)、平面波部分和式 (34)。对前者的同列解三场恒等关系已证明；对后者明确统一变量、频率、介质端态与谱参数，但未宣称其式 (34) 在原文特定常数取值下与本文公式逐项相同。
