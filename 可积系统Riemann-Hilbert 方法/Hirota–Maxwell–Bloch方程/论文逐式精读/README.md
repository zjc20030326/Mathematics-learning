**请注意两种层次**：

1. 「正文证明了什么」：基于原论文所列假设解释定理，不把条件性论断说成普遍定理。

## 全文逻辑图

初始模型及端态
→ 平面波与 Lax 对
→ 去相位常背景
→ 平方根谱曲面与单值化
→ Jost 积分方程、解析列
→ 透射/反射系数及四点离散谱
→ 跳跃矩阵、留数与归一化
→ 反射为零时的有限维系统
→ 一个完整四点轨道的**直接**代数求解
→ RHP 矩阵无穷远的光场重构 + 共振点处介质重构
→ 重建两部分 Lax 方程和原 HMB
→ 与已有 Darboux 解交叉对照。

最易混淆的四点：

- **非零背景不是只要求 η 非零**；这里是 |q|→Q>0。
- **“一个孤子”不是“w 平面仅一个极点”**；本论文的单轨道在单值化平面有四个相关点。
- **Darboux 不是第五章求解的先决条件**；最新稿先解留数系统，最后证明两种构造一致。
- **r(a)=0 是有前提的必要条件**；它既不能自动代替一般含反射 RHP 的存在性，也不保证所有阶数的光滑性。

## 文件约定和阅读方法

实际 Markdown 文件的行内数学使用单美元符号，行间数学使用独占行的双美元符号。普通位置分式使用 \dfrac{...}{...}，指数、下标中需要小分式时使用 \frac{...}{...}。物理复数单位用 \mathrm{i}，不依赖论文中的 \ii、\sg、\dd 等自定义命令。

每一节优先说明：①原文在说什么；②用到了什么已有知识；③怎么算出公式；④该结果为后文提供什么。公式索引优先使用原源码的 \label 名称；这是稳定的定位方式。

**验证边界**：这套内容属于依据现行源码写成的逐式伴读资料，不构成对全文数学定理的新一轮独立证明或一般 IST 的可解性报告。个别高级结论（尤其第五章对数导数重构及阈值处可去性）仍应以论文证明、原始文献和个人复核为准。
