## 四、重要的依赖关系

**主线 A：构造 Jost 解**

eq:background → eq:gauge → eq:F → eq:uniform → eq:E → eq:theta → eq:volterra → thm:jost。

**主线 B：构造 RHP**

thm:jost → eq:Sdef → eq:wronskian → eq:conjugation 与 eq:musheet → prop:quartet → eq:Mdef → eq:jump → eq:resplus、eq:resminus、eq:cpair。

**主线 C：直接求一轨道**

eq:partialfraction → eq:finite1、eq:finite2 → eq:finite-schur → eq:onezeros、eq:onec → eq:one-AB → eq:one-schur-det → eq:direct-vu1、eq:direct-vu2 → eq:explicitM。

**主线 D：恢复 HMB**

eq:explicitM → eq:reconq 与 eq:RfromM → eq:finalfields → eq:inverse-log-lax → eq:inverse-V-form → eq:zc → eq:HMB。

**主线 E：共振正则性**

eq:Rbg → prop:resonance → eq:timer → prop:oscillatory-regularity → prop:resonant-regularity。

## 五、学习时应该特别回避的概念混淆

1. **空间谱函数**与**传播演化矩阵**属于两个 Lax 方向；共振点 a 使后者奇异，但前者在 a 可以正则。
2. **整个 Jost 矩阵有定义**与**两列在某复域解析**是不同表述。
3. **r≡0** 与 **r(a)=0** 不同；前者是整条连续谱上的无反射问题，后者仅是一个点的必要相容条件。
4. **一轨道**含完整四点，m=2 是 D₊ 的点数，并不等于两个完全自由的孤子。
5. **Schur 系统有解** 与 **RHP 及其逆 Lax 全部条件验证成功**不同。
6. **与 Darboux 解代数一致** 不等于 **本论文从 Darboux 起步**；当前第五章已经先求直接 RHP，后做 Darboux 比较。
7. **局部 C^k 判据** 不等于 **一般含反射数据的全局 IST 可解性**。
